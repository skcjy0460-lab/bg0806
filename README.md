# 병원 블로그 AI 자동 생성기

병원 마케팅용 블로그 글을 4단계(키워드 분석 → 제목 → 구조 설계 → 본문 작성)로 자동 생성하고,
의료광고법 위반 소지를 자동으로 검수해주는 Streamlit 앱입니다.

## 주요 기능

1. **황금 키워드 분석**: 주제·진료과·지역을 입력하면 대표/서브/연관 키워드와 제목 후보 3개를 AI가 생성
2. **글 구조 설계**: SEO에 유리한 H2 소제목 구조를 자동 설계, 표에서 직접 수정 가능
3. **본문 자동 작성**: 설계된 구조를 바탕으로 완성된 블로그 본문 작성 (마크다운)
4. **의료광고법 자동 검수** (핵심 차별점):
   - 1차: 의료법 제56조·의료광고 자율심의기준 기반 금지표현 룰베이스 스캔 (정규식)
   - 2차: Gemini AI가 문맥을 이해해 위반 소지 표현과 대체 표현을 제안
   - 피부과·성형외과·치과 등 사전심의 민감 진료과는 입력 단계에서 자동 안내
5. 본문 전체 복사(클립보드), .md 다운로드, 세션 내 임시 저장

## 실행 방법 (로컬)

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud 배포

1. GitHub에 이 폴더를 업로드 (app.py, requirements.txt)
2. Streamlit Cloud에서 새 앱 생성, Main file path를 `app.py`로 지정
3. **Settings → Secrets**에 아래 내용 등록 (권장 - 매번 API 키 입력 불필요):

```toml
GEMINI_API_KEY = "여기에_발급받은_키_입력"
```

4. Secrets를 등록하지 않으면 앱 실행 시 사이드바에서 직접 API 키를 입력해도 동작합니다.

## 모델 관련 참고

- 사이드바에서 모델을 선택할 수 있습니다 (`gemini-2.5-flash`, `gemini-2.0-flash`, `gemini-2.5-pro`, `gemini-1.5-flash`)
- 특정 모델이 계정에서 404 등 오류가 날 경우, 다른 모델로 즉시 전환해 재시도해보세요.
  (Gemini는 신규 계정/API 버전에 따라 사용 가능한 모델이 다를 수 있습니다.)

## 의료광고 검수 기능에 대한 중요 안내

`PROHIBITED_PATTERNS` 딕셔너리(app.py 상단)에 정의된 금지표현 목록은 의료법 제56조 및
의료광고 자율심의기준을 참고해 만든 **자동 스크리닝용 예시 목록**이며, 완전하지도 법적 판단을
대체하지도 않습니다. 실제 게재 전에는 반드시 대한의사협회 등 자율심의기구의 사전심의를
받으시길 권장합니다. 이미 만드신 "의료광고 사전심의 가이드" 앱의 체크리스트 데이터를 이
목록에 이어 붙이면 검수 정확도를 훨씬 더 높일 수 있습니다 (`app.py`의 `PROHIBITED_PATTERNS`
딕셔너리에 카테고리와 정규식 패턴을 추가하는 방식).

## 향후 확장 아이디어

- 병원 프로필 저장 기능 (Supabase 연동) → 글마다 자동으로 병원명/주소/전화번호 CTA 삽입
- 생성 이력 영구 저장 (현재는 세션 임시 저장)
- 진료과별 전용 프롬프트 템플릿 세분화 (예: 정형외과 vs 피부과 어휘 톤 차이)
- 생성된 글을 네이버 블로그 API 등과 연동해 초안 자동 업로드
